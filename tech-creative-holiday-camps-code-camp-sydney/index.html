About this activity

Code Camp has quietly become one of Australia's most popular school holiday programs — and for good reason. These week-long in-person camps turn screen time into skill time, giving kids aged 5–12 the chance to build real projects in coding, robotics, game design and more, guided by experienced instructors who make technology genuinely exciting.

Across multiple Sydney locations, camps run all week with extended hours available at selected venues. Whether your child is into Minecraft, Roblox, robotics or stop-motion film-making, there's a camp track built around their interest. And right now, you can save $25 on any camp booking using the code WOS25 at checkout — making it even better value.

Families can look forward to:

  • Week-long immersive camps for children aged 5–12 across multiple tracks
  • Minecraft Engineers and Minecraft Minis — build and programme real in-game worlds
  • Roblox Legends — design and create games on one of the world's biggest platforms
  • Robotics camps — programme physical robots to complete real-world challenges
  • Stop-motion animation and DJing camps for creatively-minded kids
  • 9:30am–3:30pm daily with extended hours 8am–5pm at selected venues
  • Save $25 on your booking with code WOS25 at checkout
