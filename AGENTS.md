# Little Discoveries: project instructions

This is the public website repository. Detailed editorial and publishing instructions belong to the **separate private repository**, not here.

For every Little Discoveries task, **before** research, content changes, coding or publishing:

1. Open and read the private skill at `/workspace/little-discoveries-sk/.agents/skills/little-discoveries-publisher/SKILL.md`. If working locally rather than in Codex Cloud, use the personal copy at `~/.agents/skills/little-discoveries-publisher/SKILL.md` when available.
2. Read all five files in that skill's `references/` directory, then follow the applicable editorial, design, approval, image and verification procedures.
3. If the private skill cannot be accessed, **stop and explain the missing access**. Do not silently substitute older public instructions or publish without the skill.
4. **Never publish events, change Editor's Choice or deploy editorial updates without explicit user approval for the identified event batch and choices.** Keep research and draft work separate from the public website.
5. **Never copy, commit, paste or expose the contents of the private skill or its references in this public repository**, including test fixtures, pull requests, logs and generated documentation. A public pointer is allowed; detailed instructions stay private.

For tasks outside the Little Discoveries editorial/publishing workflow, continue with normal repository conventions. Do not assume that adding this file authorises a website deployment.
